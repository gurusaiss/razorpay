Where this sits in a Razorpay recurring-payments flow

Nirantar reads the mandate/attempt event stream, scores each upcoming debit inside the RBI-mandated 24h pre-debit window, and returns one decision — retime, notify, split, or hold — back through the merchant's existing notification and scheduling path. It never intercepts the debit call itself; the gateway still executes and reports the outcome.
